# service — страница услуги: хаб и концепции (`contents/templates/contents/service_detail.html`)

Перед сценариями — обернуть `window.open` (приём — `README.md`). Источник и компанию заявки
смотреть в админке «Заявки» (или `feedback_feedbackrequest`).

## concept-request — заявка с концепции открывает её PDF

С блока 1 season-2027. Для каждой концепции: `/services/legends/`, `/services/teleport-2037/`,
`/services/immersive-show/`.

1. Hero-кнопка «Получить презентацию» → модалка → ФИО `e2e приёмка <слаг>-hero`, телефон,
   компания `e2e` → «Отправить заявку».
2. Инлайн-форма «Получите презентацию <КОНЦЕПЦИЯ>» внизу страницы → ФИО
   `e2e приёмка <слаг>-inline`, телефон → «Получить презентацию».

Ожидание: после каждой отправки — «Заявка успешно отправлена!», через ~1,5 с новая вкладка с PDF
этой концепции (`legends-2027.pdf`, `teleport-2037.pdf`, `immersive-show-2027.pdf`), модалка
закрыта. Источник: hero — «Скачать Получить презентацию - <КОНЦЕПЦИЯ>», инлайн — «Услуга:
<КОНЦЕПЦИЯ> - Форма на странице». Hero каждой концепции — в своём акценте (LEGENDS — бордо и
золото, TELEPORT 2037 — графит и синий, IMMERSIVE SHOW — светлое золото).

## hub-request — заявка с хаба без PDF

1. `/services/korporativnye-vecherinki-pod-klyuch/`: на странице три карточки концепций, шаги
   «Как мы работаем», шесть пунктов «что входит».
2. Hero «Получить консультацию» → модалка → отправить заявку `e2e приёмка hub-hero`.
3. Инлайн-форма внизу → отправить `e2e приёмка hub-inline`.

Ожидание: обе заявки созданы, источник содержит «Новый год 2027 — корпоратив под ключ»; PDF не
открывается (`__opened` пуст); инлайн показывает «…Мы свяжемся с вами в ближайшее время.»

## no-company — компания необязательна, ФИО обязательно

1. На любой концепции инлайн-форма: заполнить только телефон → отправить.
2. Заполнить ФИО, компанию оставить пустой → отправить.

Ожидание: шаг 1 — форма не уходит, браузер подсвечивает ФИО («Заполните это поле»), заявки нет;
шаг 2 — заявка создана, компания «Не указано». То же в модалке (шаг 5 `layout:modal-pdf-reset`).

## blocked-window — браузер заблокировал окно PDF: ссылка «Открыть документ»

С блока 3 season-2027 (SN-19: Safari на iPhone блокирует `window.open` не по нажатию). Эмуляция —
до отправки `window.open=()=>null` (приём — `README.md`). Любая концепция, например
`/services/immersive-show/`.

1. Hero «Получить презентацию» → модалка → ФИО `e2e приёмка blocked-hero`, телефон → «Отправить
   заявку»; подождать 3 с.
2. Нажать «Открыть документ» в сообщении модалки.
3. Инлайн-форма внизу → ФИО `e2e приёмка blocked-inline`, телефон → «Получить презентацию»;
   подождать 3 с.

Ожидание: шаг 1 — «Заявка успешно отправлена!» и под ним ссылка «Открыть документ» на PDF
концепции (`immersive-show-2027.pdf`), модалка сама не закрывается; шаг 2 — новая вкладка с PDF,
модалка закрылась; шаг 3 — в сообщении инлайн-формы та же ссылка на тот же PDF. Заявки созданы,
источники — как в `concept-request`.
